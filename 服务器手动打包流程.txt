WebSSH 离线安装包手动打包流程

适用场景：
- 在 Linux 服务器上手动生成可离线部署的 tar 包
- 目标是把 WebSSH 应用、node_modules、官方 Node runtime 一起打进安装包
- 避免再次出现 glibc 冲突、node_modules 路径错误、runtime 不完整等问题

一、打包原则

1. 必须使用官方 Node 运行时目录
   推荐版本：node-v12.22.12-linux-x64

2. 不要只拷贝 /usr/bin/node
   只拷贝 /usr/bin/node 会缺少 libnode.so 等依赖。

3. 不要把系统 glibc 相关库打进包
   严禁把以下文件塞进安装包：
   - libc.so.6
   - ld-linux-x86-64.so.2

4. node_modules 必须放在 app 目录下面
   正确结构：
   - app/node_modules/
   错误结构：
   - 顶层 node_modules/

5. scripts、systemd、config 与 app 同级放置

二、最终正确目录结构

打包目录应为：

webssh-offline-linux-x64-v1.0.0/
├─ app/
│  ├─ server.js
│  ├─ index.html
│  ├─ package.json
│  ├─ package-lock.json
│  ├─ README.txt
│  └─ node_modules/
├─ runtime/
│  └─ node/
│     ├─ bin/
│     ├─ lib/
│     ├─ include/
│     └─ share/
├─ scripts/
├─ systemd/
├─ config/
├─ logs/
└─ run/

三、准备工作

假设：
- 项目目录：/opt/webssh-src
- 打包输出目录：/opt/webssh-release
- 官方 Node 压缩包下载目录：/root/node-offline

先创建目录：

mkdir -p /opt/webssh-src
mkdir -p /opt/webssh-release
mkdir -p /root/node-offline

四、准备项目文件

把以下文件放入 /opt/webssh-src：
- server.js
- index.html
- package.json
- package-lock.json
- README.txt
- scripts/
- systemd/
- config/

如果 node_modules 还没有，需要先在 Linux 服务器生成：

cd /opt/webssh-src
npm install --production --no-audit --no-fund

确认生成后：

ls -la /opt/webssh-src/node_modules

五、下载官方 Node runtime

进入下载目录：

cd /root/node-offline

下载官方 Node 12.22.12：

curl -fL -o node-v12.22.12-linux-x64.tar.xz https://nodejs.org/dist/v12.22.12/node-v12.22.12-linux-x64.tar.xz

解压：

tar -xJf node-v12.22.12-linux-x64.tar.xz

验证：

/root/node-offline/node-v12.22.12-linux-x64/bin/node -v

预期输出：

v12.22.12

六、组装离线包目录

先清空旧目录：

rm -rf /opt/webssh-release/webssh-offline-linux-x64-v1.0.0

创建目录：

mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/scripts
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/systemd
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/config
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/logs
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/run

复制 app 文件：

cp /opt/webssh-src/server.js /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/index.html /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/package.json /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/package-lock.json /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/README.txt /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp -a /opt/webssh-src/node_modules /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/

复制脚本和模板：

cp -a /opt/webssh-src/scripts/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/scripts/
cp -a /opt/webssh-src/systemd/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/systemd/
cp -a /opt/webssh-src/config/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/config/

复制官方 Node runtime：

cp -a /root/node-offline/node-v12.22.12-linux-x64 /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime/node

七、关键检查

1. 确认 node_modules 在 app 目录内：

ls -la /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/node_modules

2. 确认 runtime 是官方 Node 目录：

/opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime/node/bin/node -v

3. 确认没有把 glibc 文件打进去：

find /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime/node -name 'libc.so.6' -o -name 'ld-linux-x86-64.so.2'

预期结果：
- 没有任何输出

八、生成 tar 包

cd /opt/webssh-release

tar -czf webssh-offline-linux-x64-v1.0.0.tar.gz webssh-offline-linux-x64-v1.0.0

生成校验文件：

sha256sum webssh-offline-linux-x64-v1.0.0.tar.gz > webssh-offline-linux-x64-v1.0.0.tar.gz.sha256

查看结果：

ls -lh /opt/webssh-release/webssh-offline-linux-x64-v1.0.0.tar.gz
ls -lh /opt/webssh-release/webssh-offline-linux-x64-v1.0.0.tar.gz.sha256

九、安装前检查

在目标服务器解压后，先看结构：

tar -xzf webssh-offline-linux-x64-v1.0.0.tar.gz
cd webssh-offline-linux-x64-v1.0.0
ls -la
ls -la app

重点确认：
- app/node_modules 存在
- runtime/node/bin/node 存在

十、安装命令

chmod +x scripts/*.sh
./scripts/install.sh --install-dir /opt/webssh --service-name webssh --port 3010

安装后检查：

/opt/webssh/scripts/status.sh
curl http://127.0.0.1:3010/health

预期结果：
{"ok":true}

十一、常见错误与处理

1. 报错 status=127
原因：
- runtime 不完整
- 用了 /usr/bin/node 而不是官方 runtime

处理：
- 改用官方 node-v12.22.12-linux-x64 整目录

2. 报错 GLIBC_PRIVATE not defined
原因：
- 把 libc.so.6 或 ld-linux-x86-64.so.2 打进包了

处理：
- 删除这些文件
- 用官方 Node runtime 重新打包

3. 报错 GLIBC_2.28 not found
原因：
- 用了和目标机器不兼容的二进制或系统库

处理：
- 不要手工拼系统库
- 使用官方 Node runtime

4. 服务启动失败但 curl 过几秒正常
原因：
- 刚启动时探活过早

处理：
- 稍等 2 到 3 秒再执行：
  curl http://127.0.0.1:3010/health

tar -xJf node-v12.22.12-linux-x64.tar.xz
rm -rf /opt/webssh-release/webssh-offline-linux-x64-v1.0.0
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/scripts
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/systemd
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/config
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/logs
mkdir -p /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/run
cp /opt/webssh-src/server.js /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/index.html /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/package.json /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/package-lock.json /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp /opt/webssh-src/README.txt /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp -a /opt/webssh-src/node_modules /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/app/
cp -a /opt/webssh-src/scripts/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/scripts/
cp -a /opt/webssh-src/systemd/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/systemd/
cp -a /opt/webssh-src/config/. /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/config/
cp -a /root/node-offline/node-v12.22.12-linux-x64 /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime/node
find /opt/webssh-release/webssh-offline-linux-x64-v1.0.0/runtime/node -name 'libc.so.6' -o -name 'ld-linux-x86-64.so.2' | xargs -r rm -f
cd /opt/webssh-release
tar -czf webssh-offline-linux-x64-v1.0.0.tar.gz webssh-offline-linux-x64-v1.0.0
sha256sum webssh-offline-linux-x64-v1.0.0.tar.gz > webssh-offline-linux-x64-v1.0.0.tar.gz.sha256

十三、结论

以后手动打包时，只要记住三件事：
1. node_modules 放 app 目录里
2. runtime 使用官方 Node 整目录
3. 不要打入 libc.so.6 和 ld-linux-x86-64.so.2
