95 MB 全栈包 · 一行装机

目标机不需要联网、不需要 yum、不需要 npm/pip。Node 12.22.12 + CPython 3.11.10 全部自带,systemd 双服务联动启停。

STEP 01
本机打包

node scripts/build-fullstack-on-server.js 在服务器组装,scp 拉回 dist/。

STEP 02
上传 + 校验

scp 到目标机 /root/,sha256sum -c 比对完整性。

STEP 03
解压 + install

tar -xzf 后 ./install-all.sh,自动渲染 systemd unit、启动双服务。

STEP 04
三重探活

systemctl is-active + /health 200 + /protocol/ 200,失败自动回滚到 .bak。

# 目标机一次性装机(无外网) $ tar -xzf webssh-fullstack-offline-linux-x64-v1.0.0-*.tar.gz $ cd webssh-fullstack-offline-linux-x64-v*/ $ ./install-all.sh ↳ 解压 runtime/node + protocol/runtime/python ↳ 渲染 webssh.service + webssh-protocol.service ↳ systemctl daemon-reload && enable && start ↳ curl /health → {"ok":true} # 验证 $ systemctl is-active webssh webssh-protocol active active $ curl -s http://127.0.0.1:3010/health {"ok":true}
