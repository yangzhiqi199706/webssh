目标服务器离线安装命令清单

安装包文件：
- webssh-offline-linux-x64-v1.0.0.tar.gz
- webssh-offline-linux-x64-v1.0.0.tar.gz.sha256

默认安装参数：
- 安装目录：/opt/webssh
- 服务名：webssh
- 端口：3010

一、在本机上传安装包到目标服务器

如果目标服务器是 192.168.50.10，可在本机执行：

scp webssh-offline-linux-x64-v1.0.0.tar.gz root@192.168.50.10:/root/
scp webssh-offline-linux-x64-v1.0.0.tar.gz.sha256 root@192.168.50.10:/root/

二、登录目标服务器

ssh root@192.168.50.10

三、进入上传目录并确认文件存在

cd /root
ls -lh

四、校验安装包完整性

sha256sum -c webssh-offline-linux-x64-v1.0.0.tar.gz.sha256

预期结果：
webssh-offline-linux-x64-v1.0.0.tar.gz: OK

五、解压安装包

tar -xzf webssh-offline-linux-x64-v1.0.0.tar.gz
cd webssh-offline-linux-x64-v1.0.0
ls -la

正常应看到以下目录：
- app
- runtime
- scripts
- systemd
- config
- logs
- run

六、执行安装

chmod +x scripts/*.sh
./scripts/install.sh --install-dir /opt/webssh --service-name webssh --port 3010

七、检查服务状态

/opt/webssh/scripts/status.sh

或者：

systemctl status webssh --no-pager

八、检查探活接口

curl http://127.0.0.1:3010/health

预期结果：
{"ok":true}

九、浏览器访问

http://192.168.50.10:3010

一次性顺序执行版

cd /root
tar -xzf webssh-offline-linux-x64-v1.0.0.tar.gz
cd webssh-offline-linux-x64-v1.0.0
chmod +x scripts/*.sh
./scripts/install.sh --install-dir /opt/webssh --service-name webssh --port 3010
/opt/webssh/scripts/status.sh
curl http://127.0.0.1:3010/health


常用运维命令

启动：
/opt/webssh/scripts/start.sh

停止：
/opt/webssh/scripts/stop.sh

状态：
/opt/webssh/scripts/status.sh

卸载：
/opt/webssh/scripts/uninstall.sh

查看日志：
journalctl -u webssh -n 100 --no-pager

如果外部无法访问，再检查以下内容

查看端口监听：
ss -lntp | grep 3010

查看防火墙：
firewall-cmd --list-ports

开放端口：
firewall-cmd --permanent --add-port=3010/tcp
firewall-cmd --reload
firewall-cmd --list-ports

下一步建议：
1. 先把 dist/webssh-offline-linux-x64-v1.0.0.tar.gz 上传到目标服务器。
2. 按上面的“一次性顺序执行版”完成安装。
3. 安装后先用 curl 检查 /health，再用浏览器访问页面。
