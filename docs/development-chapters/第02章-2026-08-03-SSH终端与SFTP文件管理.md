# 第02章 - SSH 终端与 SFTP 文件管理

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

在浏览器中提供受控的 SSH 终端和同连接复用的 SFTP 文件管理能力，减少运维人员在多个工具间切换。

## 开发范围

- SSH PTY 终端连接、输入输出转发、尺寸同步和多会话管理。
- SFTP 目录浏览、上传、下载、编辑、新建、重命名与删除。
- 终端快捷命令、会话空闲处理和文件操作状态提示。

## 关联文件

- `server.js`
- `index.html`
- `lib/`

## 实现摘要

服务端基于 `ssh2` 建立 PTY 及 SFTP 通道，浏览器通过 WebSocket 与 HTTP 文件接口完成交互。文件区复用当前 SSH 连接，避免存储额外远端凭据；用户界面在目录变更和传输时保留必要的状态反馈。

## 验证记录

- 本地启动后连接测试主机，验证终端回显、目录刷新和普通文本文件编辑。
- 部署后通过 `/health` 与实际 SSH 会话验证服务可用。

## 后续注意事项

- 涉及删除、覆盖或批量操作时必须保留二次确认与明确目标路径。
- 新增远端文件能力时，不得绕过现有会话权限与路径校验。
