## 实现摘要与交付产物

- 保留 `/www/dbconfig.json` 优先读取行为，仅在文件不存在时回退到 `/www/python/src/collection/dbconfig.json`、`/www/wwwroot/localhost_8086/wwwroot/dbconfig.json`。已有文件损坏、权限异常或不支持的数据库类型均停止读取，不自动切换数据源。
- 兼容 UTF-8 BOM；Docker 与常见 MySQL 失败返回预设的具体分类，不返回原始 stderr、配置内容或 SQL 数据。
- 热更新只替换告警读取模块。安装器校验架构、包完整性、新文件语法、原服务健康及模块接口；原子替换前保存原文件，失败自动恢复，手动回滚拒绝覆盖后续更新。无数据库写入或新增运行时依赖。
- `dist/webssh-b-alarm-db-hotfix-linux-arm64-20261014174032.tar.gz`：7524 字节，配套 `.sha256`。
- `dist/webssh-b-alarm-db-hotfix-linux-x64-20261014174032.tar.gz`：7518 字节，配套 `.sha256`。
- 两包 JavaScript 补丁 SHA256 相同：`97a4499340fd114be7a7e1cb48b726f805fa18a9910c045dc132ef3c44e65b0f`。
- 校验记录：`dist/webssh-b-alarm-db-hotfix-20261014174032.verification.json`。本次交付为两种架构的热更新包，不重建既有全栈安装包。

## 后续注意事项

- ARM64 与 x64 共用源码及热更新产物已同步；均未将补丁部署到生产主机，不能声称现场批量读取已经修复。用户之前提供的采集端配置替换诊断成功返回 4 条规则，用于确认修复方向，不作为安装后的实机验证。
- 安装需在宿主机 Bash 使用 root 执行，不能在 DCIM 容器内执行。默认重启 `webssh`，可能按 systemd 配置联动协议助手；终端和转发连接可能短暂中断。无需重启 Docker、DCIM 或 MySQL。
- 安装后应在 B 接口界面对真实所选设备重新读取并核对告警预览。保存热更新解压目录及安装器输出的备份编号，便于回滚。
- 后续扩展本功能时，新增下一章记录具体变更，不回写本章的已交付结论。
