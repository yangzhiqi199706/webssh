# 第06章 - 系统设置与网络防护

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

集中管理 WebSSH 服务运行涉及的主机设置、日志、时间、IP 和防火墙策略，减少直接登录服务器手工修改的频率。

## 开发范围

- 运维设置、日志轮转、SSH 空闲超时、Docker 重启倒计时。
- IP 信息读取与设置、网络重启、系统时间与 NTP 配置。
- 防火墙状态、端口、转发和地址规则管理。

## 关联文件

- `index.html`
- `server.js`
- `tests/ops-settings*.test.js`
- `tests/log-rotation.test.js`
- `tests/ssh-idle-timer.test.js`

## 实现摘要

设置项在服务端集中持久化并校验，前端按运维、时间、IP、防火墙、账号管理等分组展示。可能改变网络连通性或系统服务的操作由接口明确返回执行结果，供用户判断是否需要进一步处理。

## 验证记录

- 设置、日志轮转、空闲超时和运维导航具备独立回归测试。
- 网络类操作应在目标环境以非生产或明确窗口完成手工验证。

## 后续注意事项

- 新增系统级操作前先说明影响范围、回滚路径和权限要求。
- 防火墙与网络设置属于高风险变更，界面必须保留确认提示和可读错误信息。
