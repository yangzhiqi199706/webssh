## 实现摘要

- 新建连接增加 SSH 主机 / Docker 容器选项；使用宿主机凭据和容器名称或 ID。
- 容器终端通过 SSH exec 的 PTY 运行 docker exec，退出即关闭会话；不存在回落到宿主机 shell 的流程。
- 文件适配器在同一 SSH 连接上执行容器内 Python 3，复用原文件管理界面及消息契约。路径与内容通过 JSON stdin 传递，不拼接到命令字符串。
- 文件管理从容器 `/` 开始，支持目录浏览、拖拽上传、下载、文本编辑、新建文件/目录、文件删除与重命名。删除目录不在本次范围。
- 容器名严格校验；普通文件读写排除设备及虚拟系统路径；操作超时 60 秒，最多同时 4 个操作，单文件上限 32 MiB。
- 容器连接与宿主连接采用不同保存键，保留容器名大小写；页面标签显示容器名，旧连接消息不能污染新会话。
- 容器模式拒绝宿主机 SNMP 部署，且正确结束前端等待状态。
