# 第12章 - 协议助手文档处理平台

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

以 `/protocol` 子路径提供面向协议资料的 Excel、PDF 与文档批处理工具，并与主壳视觉风格和部署体系一致。

## 开发范围

- XLS 清洗、故障编码填充、PDF 与 Excel 对照编辑。
- MBP 文件生成和协议文件批量处理。
- Flask 子站反向代理、离线 Python 运行时与静态资源本地化。

## 关联文件

- `protocol_app/app.py`
- `protocol_app/modules/`
- `protocol_app/templates/`
- `protocol_app/static/`
- `systemd/webssh-protocol.service.template`
- `scripts/deploy-protocol.js`

## 实现摘要

Flask 应用通过 DispatcherMiddleware 挂载到 `/protocol`，主壳保留完整前缀反向代理，避免常规 `app.use` 剥离路径造成 404。模板和脚本使用统一前缀注入机制，支持直连调试与经主壳访问两种模式。

## 验证记录

- 检查 `http://127.0.0.1:5000/protocol/` 与主壳 `/protocol/` 均返回 200。
- 以保留的测试样本验证各模块输入、输出和下载链路。

## 后续注意事项

- UI 调整不得破坏模板 DOM ID、请求 URL 和 JSON 字段契约。
- 运行时上传与输出目录不纳入 Git；离线依赖升级必须验证 Kylin Linux 兼容性。
