# 第13章 - 数据库管理与数据源切换

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

集中管理 dcim 容器中的 MySQL、openGauss 和达梦数据库，并提供安全的查询、备份还原、服务控制和数据源切换辅助能力。

## 开发范围

- 三库状态、版本、库表浏览与 SQL 控制台。
- 容器内原生工具备份、上传、下载和还原。
- openGauss 初始化、访问白名单、WVP 同步与序列修复。
- 达梦许可证、数据源版本管理和切换流程。

## 关联文件

- `db/index.html`
- `server.js`
- `config/db-manager.json`（运行时配置，不入 Git）
- `tests/dcim-wvp-opengauss.test.js`

## 实现摘要

数据库管理器通过 SSH 操作 dcim 容器；MySQL 的导出、导入与管理命令始终使用容器内对应版本的客户端，避免宿主机工具与生成列或 SQL 方言不兼容。配置保存时对密码脱敏并限制文件权限。

## 验证记录

- 依次验证 SSH、MySQL、openGauss、达梦连接和状态查询。
- 对备份与还原在受控库或维护窗口验证，确认生成文件、导入结果和服务恢复状态。

## 后续注意事项

- 任何停止数据库或切换数据源的操作都会影响 dcim 业务，必须保留二次确认、备份和回滚记录。
- 数据源切换不等于数据迁移；迁移过程需由独立章节记录。
