# 第04章 - TCP 调试与网络会话

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

提供浏览器内 TCP 调试能力，用于连接测试、报文收发、网络协议联调，并与串口转网口形成互补。

## 开发范围

- TCP WebSocket 通道与连接状态展示。
- 目标地址和端口连接、报文发送、接收日志与断开控制。
- 与串口转网口监听端口配合，用于串口链路的网络侧调试。

## 关联文件

- `index.html`
- `server.js`

## 实现摘要

主壳将浏览器调试操作映射为服务端 TCP Socket 生命周期，并将连接、数据、错误和关闭事件回传界面。该能力仅负责调试通信，不替代协议转换子站的长期运行转发服务。

## 验证记录

- 本地启动后使用可达 TCP 服务验证连接、收发与主动断开。
- 与串口桥接端口联调时，确认停止桥接后 TCP 连接不可再建立。

## 后续注意事项

- 长报文或二进制协议扩展需明确编码、分帧和日志截断策略。
- 不得把敏感业务报文或凭据长期写入浏览器本地存储。
