# 第07章 - 本地账号与访问控制

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

在不限制服务器上既有程序运行的前提下，对 WebSSH 登录入口实施本地账号、角色和来源地址控制。

## 开发范围

- 本地账号登录、密码修改、密码有效期与过期提示。
- 角色分级、临时授权的创建与撤销。
- 登录 IP 白名单与访问控制策略。

## 关联文件

- `login.html`
- `index.html`
- `server.js`
- `tests/access-control.test.js`
- `tests/local-account-*.test.js`

## 实现摘要

认证与账号管理由主服务提供 API，页面负责登录、策略维护和用户操作反馈。该方案仅保护 WebSSH 应用访问，不修改 Linux 系统账号、systemd 服务或已部署业务程序的运行权限。

## 验证记录

- 访问控制、本地账号服务、登录界面和账号管理界面均有自动化测试。
- 登录、密码过期和白名单策略变更后应重新验证当前会话行为。

## 后续注意事项

- 账号配置与密码不得记录在章节、测试夹具或 Git 仓库中。
- 若后续接入 LDAP/AD，应单独立项并记录本地账号回退机制。
