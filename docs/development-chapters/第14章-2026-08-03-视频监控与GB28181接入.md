# 第14章 - 视频监控与 GB28181 接入

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

接入 GB/T 28181 视频设备，提供设备状态、实时预览、历史回放和云台控制，并兼容现有 dcim 视频服务。

## 开发范围

- WVP、ZLMediaKit、Redis 与 WebSSH 主壳协同运行。
- 设备与通道读取、实时播放、回放控制、停止上游流和 PTZ。
- dcim 视频服务与 WebSSH 视频服务的状态/通道代理。

## 关联文件

- `video/index.html`
- `video/vendor/README.md`
- `server.js`
- `systemd/`

## 实现摘要

视频模块通过主壳 API 汇总设备和流状态，并将播放/停止生命周期显式化，避免关闭视图或切换分屏后遗留上游流。静态播放器资源采用离线固定版本，适配内网部署要求。

## 验证记录

- 检查媒体服务、WVP、Redis 和 WebSSH 服务状态。
- 使用已接入设备验证设备发现、实时预览、停止播放、回放与 PTZ。

## 后续注意事项

- 播放协议、端口和跨域配置变更需同步验证浏览器、媒体服务和设备网络三端。
- 当前不把 WebRTC/HLS 和本地录像列为默认交付范围，扩展时另建章节。
