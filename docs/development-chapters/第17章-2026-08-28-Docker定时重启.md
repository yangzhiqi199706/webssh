日期：2026-08-28
状态：功能记录

## 功能目标

在运维板块新增按分钟配置的 Docker 循环重启任务：倒计时结束执行 systemctl restart docker，成功后自动进入下一轮，失败后暂停并展示执行结果。

## 后续注意事项

- 新功能默认关闭；启用后立即开始第一轮倒计时，服务重启后会按持久化配置重新进入倒计时。
- 重启失败会暂停循环，需确认 Docker/systemd 状态后使用“重新倒计时”或修正配置。
- 该操作会中断 Docker 容器和依赖服务，生产环境应设置足够长的间隔并在维护窗口启用。
- 后续扩展本功能时，新增下一章记录具体变更，不回写本章的已交付结论。
