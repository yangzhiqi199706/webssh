## 新功能自动归档

完成新功能、功能性修复或运维能力扩展后，在提交或部署前执行：

```powershell
npm run docs:chapter -- --title "功能名称" --summary "本次交付的结果" --scope "能力一,能力二" --files "server.js,index.html" --verification "npm test,手工验证步骤"
```

命令会自动分配下一个章节编号、创建标准章节模板并刷新本目录。创建后应补全“验证记录”和“后续注意事项”为实际结果。仅修改排版、拼写或不改变运行行为的锁文件时，不创建章节。

## 章节写作要求

每章至少包含：功能目标、开发范围、关联文件、实现摘要、验证记录、已知风险或后续注意事项。文档不得写入账号密码、令牌、会话信息、真实数据库连接串或其他敏感配置。
