# 第01章 - WebSSH 主壳与会话管理

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

提供浏览器中的统一运维入口，承载 SSH、串口、TCP、服务总览及各子站，并维护多主机、多会话的界面状态。

## 开发范围

- 原生 HTML 单页主壳，左侧功能菜单可按用户长按拖动顺序保存。
- WebSocket 会话、主机切换、终端标签、快捷命令、连接状态和工作区布局。
- 各专业功能通过 iframe 子站或主壳视图接入，保持统一深色运维界面风格。

## 关联文件

- `index.html`
- `server.js`
- `login.html`
- `lib/`

## 实现摘要

主壳由 Express 与 WebSocket 服务提供。菜单、视图切换、会话状态和界面偏好在前端统一管理；子站仅在首次打开时加载，避免不必要的初始化。服务端提供健康检查和各业务 API，并负责对需要受保护的管理操作进行会话校验。

## 验证记录

- `npm test`：2026-08-03 的全量回归包含菜单重排序、会话与各业务模块测试。
- `GET /health`：用于部署后的主服务存活检查。

## 后续注意事项

- 新增一级功能入口时，要同步更新主壳菜单、视图切换、懒加载和本章节档案。
- 复杂新功能优先作为独立子站接入，避免继续扩大主壳内联脚本。
