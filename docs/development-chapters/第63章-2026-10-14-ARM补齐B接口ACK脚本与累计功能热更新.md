## 功能核对结论

- 核对本地 2026-10-12、2026-10-14 的 ARM/x64 四份全栈归档及当前共享源码，共 145 份当前业务源码；不代表生产服务器实时盘点。
- 10/14 两架构安装包共享同一源码 manifest，均早于第61章动态 ACK 功能。第61章记录 x86 已部署 ACK，因此运行态 x86 不能与旧 x86 归档混淆。10/14 ARM 缺少动态 ACK 的生成器、接口及前端按钮，同时仍使用告警读取旧固定路径。
- 10/12 ARM 缺少整个 B 接口及 SAX 根依赖。累计同步 B 接口通道、告警上报与重试、AI/DI 分类、测试编码、全选/移除、CSV、WSDL、查询请求/预览、数据库告警定义映射及映射界面功能。
- ARM 两批包中其他主壳、串口、短信、HA、视频、数据库管理、协议助手源码未发现此次需要补齐的差异。10/12 旧 x64 视频 vendor 哈希和静态介绍页与当前不同，不凭哈希宣称功能缺失；本次不替换这些 x64 非 B 接口资源。
- 与当前源码比较的逐文件结果及范围限定见包内 `AUDIT.md`、`audit.json`，本地报告位于 `output/feature-sync-hotfix/20261014183929/ARM功能核对报告.md`。

## 实现与交付

- 业务源码原本已具备第61章 ACK 功能，本次增加审计、累计打包、多文件事务安装器和对应测试，将现有共享实现完整纳入两种架构交付。
- 每包包含 25 个文件：主壳 B 接口入口、完整 B 接口前后端模块及资源、package 元数据、纯 JavaScript SAX 1.4.1（含许可证）。无 x86/ARM 原生二进制，不更换运行时或第三方版本。
- 安装器在覆盖前核对已知基线哈希，拒绝未知定制修改。备份后原子逐文件替换，验证 ACK 和路由加载再重启 webssh；失败恢复原文件并删除本次新增文件，手动回滚拒绝覆盖后续更新。文件事务仅操作允许清单，不触碰 config、数据库、协议助手或运行时。
- ARM：`dist/webssh-feature-sync-hotfix-linux-arm64-20261014183929.tar.gz`，252545 字节；附同名 `.sha256`。
- x64：`dist/webssh-feature-sync-hotfix-linux-x64-20261014183929.tar.gz`，252534 字节；附同名 `.sha256`。
- 验证记录：`dist/webssh-feature-sync-hotfix-20261014183929.verification.json`。本包包含第62章告警读取修复，无需先装上一轮单文件补丁；已经安装上一补丁也受支持。

## 后续注意事项

- ARM 与 x64 热更新已同步打包及本地验证；本轮未连接或部署任一生产服务器，未执行实际 ARM Node/systemd 实机安装。Bash 夹具的架构、systemd、curl 和依赖探测使用替身；历史快照模块验证使用本地 Node 和本地既有依赖。不要将这些结果表述为 ARM 实机业务验证。
- 仅交付累计热更新，不重建旧全栈安装包；既有全栈包保留。若未来需要完整初装包，应由共享源代码重新生成两架构产物。
- 在宿主机使用 root 执行安装。webssh 重启会短暂中断终端和转发，协议助手可按 systemd 联动重启；不重启 Docker/DCIM/MySQL。
- 安装后 Ctrl+F5 刷新，在接入配置的“SoapUI / 告警 ACK 自动响应”展开脚本或复制脚本/响应正文，按已保存 SOAP 绑定生成；随后验证批量告警定义预览。现有接入身份、设备测点映射和业务状态保留，不自动替用户改 SoapUI 或上级平台配置。
- 后续扩展本功能时，新增下一章记录具体变更，不回写本章的已交付结论。
