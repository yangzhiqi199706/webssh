# 第03章 - 串口调试与串口转网口

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

支持本机或浏览器 WebSerial 串口调试，并将已扫描到的 Linux 串口按配置转换为 TCP 服务或远端转发通道。

## 开发范围

- 串口扫描、波特率、数据位、校验位、停止位及报文间隔配置。
- `/dev/ttyS*` 串口到 TCP 监听端口的桥接，以及 TCP 到串口的转发。
- 单端口启停、批量启动已启用端口、停止全部、开机自启及配置持久化。
- 串口占用锁、启动/停止竞态处理和残留子进程清理。

## 实现摘要

桥接管理器为每个读写侧子进程创建独立进程组。停止桥接时先关闭监听与连接，再向进程组发送终止信号并进行超时兜底清理，避免页面已停止但串口或 TCP 端口仍被残留进程占用。服务启动时会读取持久化的自启动配置。

## 验证记录

- `tests/serial-bridge-*.test.js`：覆盖配置校验、双向转发、批量操作、自启动、进程 I/O、失效锁和启动停止竞态。
- 2026-08-03 在目标机验证：停止 `/dev/ttyS4` 桥接后设备无占用、监听端口释放；恢复启动后端口重新监听。

## 后续注意事项

- 出现“设备被占用”时先检查对应桥接状态、`fuser` 和监听端口，避免误判为外部程序。
- 新增串口类型或协议解析时，必须保持停止路径能回收所有文件描述符和子进程。
