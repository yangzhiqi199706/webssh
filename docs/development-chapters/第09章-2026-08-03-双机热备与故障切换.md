# 第09章 - 双机热备与故障切换

日期：2026-08-03
状态：现有功能基线整理

## 功能目标

提供双机环境的连接校验、数据库同步计划、故障状态观察和受控切换操作。

## 开发范围

- 主备连接配置与 SSH、数据库连通性测试。
- 手工同步、定时同步、同步状态和 MySQL 参数调优。
- 故障切换状态、测试、停止和复位操作。

## 关联文件

- `ha/index.html`
- `server.js`
- `config/`（运行时配置，不入 Git）

## 实现摘要

热备模块通过 SSH 控制对端和 dcim 容器内的原生数据库工具。备份、导入与参数处理遵循“容器内工具版本与数据库一致”的原则，避免宿主机 MariaDB 客户端与 MySQL 产生不兼容数据。

## 验证记录

- 连接测试、同步状态读取和故障切换测试应在隔离或明确维护窗口执行。
- 配置变更后检查同步计划、服务状态和故障切换保护状态。

## 后续注意事项

- 真正的故障切换会影响业务写入方向，必须经过人工确认，不应由趋势告警自动触发。
- 出现数据库连接错误时使用渐进退避，避免触发 MySQL 主机错误计数封锁。
