# 移除设置更新功能设计

## 目标

彻底移除 WebSSH 设置中的 8081 src 覆盖更新功能，不影响通用 SSH 与 SFTP 文件管理。

## 删除范围

- 从 `index.html` 删除“更新”设置标签、对应页面结构及全部更新专用前端状态、事件处理和刷新调用。
- 从 `server.js` 删除 `update:apply` WebSocket 消息处理，不再接受上传 tar.gz 后覆盖 `/dcim/admin/localhost_8081/wwwroot/src` 的请求。
- 删除 `scripts/pack-8081-src.bat`，不再提供该功能的打包入口。

## 保留范围

- 保留 SSH 连接生命周期和 SFTP 初始化逻辑。
- 保留文件管理模块的上传、下载、编辑、重命名和目录浏览能力。
- 不改变其他设置分页、WebSocket 消息或部署脚本行为。

## 验证

增加静态回归测试，断言前端、后端和脚本目录不再包含更新功能的专用标识；运行现有测试以确认未影响其他模块。
