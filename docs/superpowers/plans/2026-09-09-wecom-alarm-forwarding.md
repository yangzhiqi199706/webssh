# 企业微信群机器人告警转发实施计划

**Goal:** 在协议转换中提供群机器人、新增告警、明确恢复通知、过滤去重、测试发送和日志。

**Architecture:** 复用 `global.__protoConv` 的 DCIM 会话，通过独立采集适配器规范化告警。独立管理器用原子 JSON 文件保存配置、基线、发送队列和最近日志；Express 路由做账号鉴权，原生页面展示配置和状态。Node 12 兼容，不增加生产依赖。

## 固定行为

恢复必须有同一告警 ID 与发生时间对应的有效恢复时间，晚于发生时间且不在未来；不根据消失、确认状态或数值状态猜测恢复。首次基线不发新增/恢复。列表解析失败不得当作空列表。队列先落盘再发送，逐条限速，失败退避；永久拒绝进入失败队列供人工重试。Webhook 只允许企业微信官方 HTTPS 地址，凭据不返回浏览器和日志。网络响应丢失与成功落盘之间的崩溃可能造成重复，不能承诺端到端 exactly-once。
