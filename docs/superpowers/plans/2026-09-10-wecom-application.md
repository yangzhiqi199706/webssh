# 企业微信自建应用实施计划

用户选择：群机器人 / 自建应用二选一。旧配置默认机器人，保留两个通道配置，不同时发送。

1. 新增独立应用发送模块：官方 HTTPS gettoken/message/send，内存 Token 缓存、并发合并、过期刷新一次；固定错误提示不回显密钥。测试缓存、失效重试、部分接收失败。
2. Forwarder 增加 channel 和 application，旧状态默认 webhook；读取隐藏 Secret；队列非空时禁止改变发送目标；日志标记通道。测试保存、迁移、保密和队列保护。
3. 表单增加通道、CorpID、AgentID、Secret、成员/部门/标签，新增凭证测试；沿用保存和发送测试接口、权限与同源检查；说明应用可见范围及出口可信 IP。
4. 运行自建应用与既有企业微信回归、全量测试；不使用真实凭证或实际发送消息。交付本地实现，缺少用户应用凭证时明确实发未验证。
