# 联通 B 接口转发配置与联调

本功能位于「协议转换 → B接口转发」。本软件充当 SU，将现有 DCIM 接口数据转换为中国联通 V3.0 的 B 接口报文；支持上级查询遥测、遥信和当前告警，以及 SU 主动注册和告警上报。默认停用。

B接口窗口打开时，点击或双击窗口外的遮罩不关闭窗口，也不改变未保存草稿。需要退出时使用右上角「关闭」或Esc；关闭仍不自动保存。

## 依据与 GitHub 调研

- 业务报文依据用户提供的《2024-中国联通动环监控系统 B 接口技术规范 V3.0》（QB/CU 132-2024），重点为 5.2.3、5.2.5、5.2.9、5.2.10.1/.2/.3/.6/.9 和 5.4。
- GitHub [htgd/wh_fsu](https://github.com/htgd/wh_fsu)：公开的动环监控工程，含 B 接口客户端/服务端和 gSOAP 代码。它的 [soapClient.c](https://github.com/htgd/wh_fsu/blob/master/soap_sc/soapClient.c) 使用 invoke/xmlData/invokeReturn；[命名空间表](https://github.com/htgd/wh_fsu/blob/master/soap_sc/SCServiceSoapBinding.nsmap) 可作为 SOAP 绑定研究参考。该实现年代和运营商报文可能不同，不作为本次联通 V3.0 字段依据，也未复制其 GPL 代码。
- XML 解析采用 [isaacs/sax-js](https://github.com/isaacs/sax-js) 的严格模式，锁定 `sax@1.4.1`，纯 JS、无原生架构依赖；禁用 DTD/实体声明，限制请求大小、嵌套深度和节点数。
- PDF 写明 SCService.wsdl/SUService.wsdl 见附件，但本次 PDF 未嵌入附件。默认命名空间、SOAP 版本、方法名和参数名只是参考绑定；必须与上级实际 WSDL 核对，不宣称已经完成运营商平台认证。

## 首次配置

1. 在「协议转换 → 连接信息」保存并验证 DCIM 连接。B 接口复用这条会话，不单独保存 DCIM 凭据。
2. 打开「B接口转发 → 接入配置」，填写 SC 注册服务的完整 URL，最多三个；填写注册账号口令。
3. 填写 SUId：本 SU 的 12 位 MAC 十六进制编码，不含冒号或横线；填写上级分配的 SU 资管编码。
4. SU 内网 IPv4 填写上级可访问的本软件服务器地址；SU 服务默认 `http://SU地址:8080/services/SUService`。可修改端口、监听地址和路径，避开本机已有服务；防火墙需允许 SC 访问该端口。
5. 上级 IP 白名单填写 SC 实际发起连接的 IP，可用逗号或换行分隔。SCIP 分配地址也必须在此白名单中；不信任 X-Forwarded-For，暂不支持 CIDR。
6. 展开 SOAP 参数，按实际 WSDL 核对版本、命名空间、方法、请求参数、响应字段和 SOAPAction。默认 1.1/invoke/xmlData/invokeReturn；支持 SOAP 1.2，业务 XML 作为字符串参数传输，接收转义文本或 CDATA。
7. 在「设备和测点」按 DCIM 设备 ID 读取参数，或导入 Modbus 已选设备；为每个设备填写联通五位设备编码和资管编码，勾选要转发的测点并填写十二位监控信息 ID。
8. 保存后到「报文预览」核对数据；再点「启用并保存」。查看状态及日志中的 LOGIN_ACK 与后续业务 ACK。

保存配置和启停仅管理员/运维账户可执行。只读账户可查看配置、预览和日志；管理接口复用现有本地登录，检查请求同源。

### SoapUI / Initial WSDL

接入配置中的「SoapUI / Initial WSDL」提供「下载 SU WSDL（查询本软件）」和「下载 SC WSDL（模拟上级）」两个按钮。已登录的只读账户也能下载；不要求启用转发。SU 下载需先保存 SU IP，SC 下载需先保存 SC 注册 URL。文件仅包含 SOAP 绑定和对应服务地址，不含注册口令、账号或设备映射；不依赖外部 XSD 下载。

下载后在 SoapUI 新建 SOAP Project，Initial WSDL 点击 Browse 选择文件。SU 用于向本软件发送查询请求；SC 文件用于 Generate MockService。WSDL 按已保存的 SOAP 1.1/1.2、方法名、请求参数、响应字段、SOAPAction 和服务地址生成。界面未保存的草稿不会改变下载文件；修改配置后需保存并重新下载或更新 SoapUI Definition。

SU 已启用并监听时，还可直接填入 `http://<SU IP>:<端口><SU服务路径>?wsdl`（也支持 `?WSDL`）。该 GET/HEAD 服务保留上级 IP 白名单，访问电脑来源 IP 需已获允许；它不依赖 WebSSH 登录，不计为 SC 心跳。转发停用时，请用界面下载文件。

主壳文件下载接口为 `GET /api/proto-conv/b-interface/wsdl/su` 和 `/wsdl/sc`，要求已有本地登录会话；SoapUI URL 导入宜使用 SU 在线地址，避免主壳会话认证问题。本软件生成的是匹配当前实现的联调 WSDL，正式平台绑定须以对方提供的 WSDL 核对。

### AI / DI / ALARM 查询请求

「查询请求」页按已保存的全部设备及测点生成三条独立标准 SOAP 报文：AI 使用 GET_AIDATA/201，DI 使用 GET_DIDATA/301，ALARM 使用 GET_ALARM/601。每条报文的 DeviceList 只包含该类型已映射的联通设备编码、资管编码和监控信息 ID，覆盖列表所有页。SUId/SURId、SOAP 1.1/1.2、命名空间、方法和参数来自已保存配置；未保存草稿不进入报文。DI 和 ALARM 的查询信号状态末两位使用 FF，AI 保留配置的基准 ID。

选择类型后可复制完整 SOAP 请求，或下载 GET_AIDATA-request.xml / GET_DIDATA-request.xml / GET_ALARM-request.xml。将全文放入 SoapUI 的 SUServiceSoapBinding → invoke → Request 1 左侧，地址使用页内显示的 SU 地址，HTTP 方法为 POST。GET_* 是业务报文名，不是 HTTP 方法；WSDL 导入仍在 Initial WSDL 完成，不能把 WSDL 内容作为查询发送。普通 HTTP 页面剪贴板不可用时会回退复制/全文选择，按提示使用 Ctrl+C。

「本机响应预览」使用现有 B 接口最近采集缓存及同一响应处理逻辑，显示完整 SOAP ACK 和采集时间；不向 SC 发送、不更新 SC 心跳。无有效采集时 AI 为空值、DI 为 FF、告警返回 Result=0；无当前未恢复告警时告警列表为空。外部 SOAP 地址及白名单连通性仍通过 SoapUI 验证。告警查询按 DeviceList 的设备与测点筛选，并保留现有恢复/队列机制。

查询生成和预览接口沿用本地登录，已登录只读账户可使用；不要求生成阶段启用转发。主壳新增 GET `/api/proto-conv/b-interface/query-requests`，POST `/api/proto-conv/b-interface/query-preview/AI`、`/DI`、`/ALARM`（POST 仍检查同源）。生成请求不包含 SC 注册账号口令，也不触发 DCIM 或上级调用。

设备列表的「全选设备 / 取消全选设备」覆盖所有页的设备，不改变测点选择或已输入编码。每页显示 10 个设备，每个设备每页显示 25 个测点；翻页保留草稿，保存覆盖所有已选设备与测点，不仅当前显示页。

「设备和测点」使用左侧设备目录、右侧单设备编辑：目录每页10项，按名称、DCIM ID、分组、联通编码或资管编码搜索；点击设备名称编辑，旁边复选框控制设备是否转发。当前设备显示分组ID/serverCode、编码和测点。测点支持全部/AI/DI/ALARM筛选及参数名、告警名、监控ID搜索，每页最多25项；各设备的筛选条件和草稿在切换时保留。

搜索/类型筛选只影响显示，顶部统计仍涵盖全部已选设备的已选测点。「全选设备」始终覆盖全部草稿设备；当前设备的「全选测点」覆盖该设备所有类型和分页。底部固定保存/CSV操作栏同样处理全部选择，包括当前搜索未显示的设备。草稿修改提示在成功保存后复位；“待填写编号”统计已选测点中空ID的数量，不代替后端校验。

设备目录的「移除全部设备」清空全部已勾选设备及其测点草稿，包含搜索隐藏项和其他页；未勾选设备及其编辑内容保留。没有勾选设备时按钮禁用，viewer不能移除。操作后清除旧告警预览、重置搜索/分页并更新数量；没有设备时显示添加入口。不自动保存，关闭后重开可恢复已保存配置。点击「保存设备和测点」才持久化；如果因批量移除而没有任何已选测点，保存时同时停用已启用的转发，界面会提前提示。后端未确认告警队列的映射变更保护保持，不强制删除告警队列或DCIM数据。

添加设备、Modbus导入和类型更新集中在上方「添加设备与批量工具」；告警定义读取/预览/导入集中在「批量告警映射」；详细填写说明和字段JSON在下方折叠区。空设备时自动展开添加工具。输入五位设备编码会覆盖全部测试ID的提示保留在编码区，正常输入不重建设备/测点表，统计更新合并延迟180ms。桌面双栏，手机纵向布局，测点表内部横向滚动，保存栏保持可见。

新读取或导入的测点按 DCIM/Modbus 的 DataType 分类：模拟量默认 AI，开关量/状态量默认 DI；类型不明确时请手动核对，不根据参数名称、0/1 当前值或 int/float 存储类型猜测。普通重复导入保留已有手动类型。以前统一设为 AI 的条目，可点击「按 Modbus 更新 AI/DI」按设备 ID+参数名匹配并更新全部页；保持编码和勾选，跳过 ALARM 告警映射，未匹配或类型冲突的条目保持原选择。核对后点击保存才持久化。

「DCIM 设备 ID」每次填写一个编号，依次读取 3、4 会加入两个设备，不填逗号分隔列表。对已有设备再次读取时更新分组和 serverCode，保留设备名称、联通编码、测点选择及手动类型；普通 Modbus 重复导入不覆盖已修正的来源配置。修改后需保存。

采集 AI/DI 时，分组查询未返回目标设备或分组接口业务失败，会回退到精确 DeviceId/serverCode 的测点查询，运行日志记录 SOURCE/fallback。单个设备参数查询失败只将其测点标记为空值/FF，健康设备继续刷新，并记录 POLL/partial 和具体设备；全体设备失败保留原失败/过期保护。DCIM 网络中断、HTTP 401/403 或会话失效时停止逐设备重复尝试。告警采集/历史查询的失败仍按原策略阻止本轮状态提交，避免误判恢复或丢失队列。

## 映射规则

| 类别 | DCIM 来源 | B 接口表现 |
| --- | --- | --- |
| AI 遥测 | 设备参数 ParaName / CurValue | GET_AIDATA_ACK，Signal 带 Id 与 Value；无有效值为空 |
| DI 遥信 | 设备参数 ParaName / CurValue | GET_DIDATA_ACK；状态写入 ID 末两位，0–99 用两位数字；缺失或无效值为 FF，不另写 Value |
| ALARM 告警 | 设备 ID（缺失时用唯一设备名称）+ 精确告警名称 | SEND_ALARM / SEND_HISALARM；GET_ALARM_ACK 返回当前未结束的已映射告警 |

AI/DI 的配置 ID 末两位填写 `00` 基准值。设备编码是五位数字，监控信息 ID 为十二位数字，两者前三位设备类型必须一致；同一设备的监控点 ID 不可重复。正式接入时编码应来自联通标准编码表。

经用户确认，联调界面支持自动生成测试 ID：输入完整五位数字设备编码后，将本设备所有测点 ID 更新为「五位设备编码 + 五位测点序号（从 00001 开始）+ 00」，例如 10012 对应 100120000100、100120000200。覆盖已填 ID、其他页及未勾选测点，但不改变勾选或 AI/DI/ALARM 类型；只有点击保存才写入配置。已填设备编码也可点击「按当前设备编码生成测试 ID」。不足五位或非数字输入不触发填充；加载现有配置不自动改 ID。生成仅更新当前页 ID 输入框和全部测点草稿，不重建设备表格。

这是独立的测试编号规则，不是联通标准监控信息编码表；正式对接须用正确标准 ID 替换。序号按当前测点列表顺序生成，增删测点或重新生成可能改变原 ID；保存过程中仍受未确认告警队列的映射变更保护。

告警映射名称默认优先识别 AlarmName、eventName，其后才识别 AlarmContent、TypeName、TextMessage，要求完全一致。旧手动动态名称通过旧字段别名兼容；若存在稳定名称映射，优先匹配稳定名称，重复匹配仍拒绝发送。存在特殊源字段时，可在「告警字段映射」指定 `alarmName`。支持 id/startedAt/recoveredAt/device/deviceId/alarmName/content/value 等源字段名配置。未映射或不能唯一匹配的告警会记录跳过数量，不发送到错误设备。

### 批量导入告警定义

在「设备和测点」勾选设备，点击「批量读取告警定义」，检查分页预览中的候选与待核对项，再点击「导入已识别告警」，核对后「保存设备和测点」。读取和导入都不会自动保存。已存在的同设备、同告警名称映射保留已有编码和勾选；新增项默认勾选；只有空 ID 的告警分配不冲突测试编号，正式对接应换成联通标准编码。

数据源必须是本软件所在主机的 DCIM MySQL；后端只读容器内固定数据库配置，使用容器内 mysql 参数化查询设备定义表 `dcim-alarmnotifymode` 与事件类型表。没有修改数据库或 DCIM 告警状态。读取最多 500 个设备、10000 条定义，导入仍受每设备 1000 个已选测点、总计 10000 个限制，超限整次拒绝。只读账户可读取/预览，不能导入或保存。设备选择或 DCIM 来源改变后需重新读取。

事件名称根据实际触发条件生成：已填上限生成「参数名+高于阈值」，已填下限生成「参数名+低于阈值」；普通告警特征值生成「参数名+告警」，例如漏水状态特征值 `1` 命中实时值 `1`（或 `1.0`）后由 DCIM 产生「漏水状态告警」。多状态格式 `*1=漏水/2=断线` 对应「漏水告警」「断线告警」，描述替代原参数名。设备连接异常按类型表生成。状态规则可能同样存储为 AlarmType=0，不能只靠规则类型判断 AI/DI 告警。

没有触发条件、名称重复、多状态特征值重复/描述不明确、未知类型或删除设备列入待核对，不自动导入。DI 映射查询当前状态，ALARM 映射转发 DCIM 已产生的告警；本软件不重新计算特征值、确认次数或恢复条件。设备恢复后再次读取的 110 条定义，按实际条件生成 62 个候选和 54 条待核对（2026-10-13）；定义数和候选数不同是因为一条规则可以包含多个触发分支。

## 已实现的报文

设备测点区域提供“全选测点 / 取消全选测点”，覆盖该设备所有分页的 AI、DI 和 ALARM 测点。旁边显示已选数量；操作不修改其他设备、设备勾选、测点类型或编码，点击“保存设备和测点”后生效。保存仍只包含已勾选设备的已勾选测点；取消选择后保存的测点如需恢复，可重新读取 DCIM 测点。

点击“导出已选测点 CSV”可导出当前全部分页中已勾选设备的已勾选测点，包含未保存的勾选和编辑；该操作不保存配置。每行包含 DCIM 设备 ID、设备名称、分组 ID、serverCode、联通五位设备编码、设备资管编码、AI/DI/ALARM 类型、参数名、告警名称和十二位监控信息 ID。导出采用 UTF-8 BOM、标准双引号转义与 CRLF 行分隔，无测点时不生成空文件；viewer 可以导出已有映射。Excel 请通过“从文本/CSV”导入，并将编码列设为文本以保留前导零。可能被表格软件当作公式的文本添加单引号前缀，避免执行源参数名或资管编码中的公式。

| 发起方 | 报文 | 行为 |
| --- | --- | --- |
| SU | LOGIN 101 / LOGOUT 103 | 注册含 SU 和设备元数据；注册 ACK 必须返回 RightLevel 1/2；停用时尝试注销 |
| SC | SET_IP 105 | 在白名单内接收 SCIP，保留已配置上级 URL 的协议、端口和路径 |
| SC | GET_AIDATA 201 / GET_DIDATA 301 | 支持全部/按设备/按监控点查询，使用最近采集缓存 |
| SC | GET_ALARM 601 | 返回已映射当前告警；未建立有效缓存/缓存过期时明确返回失败 |
| SC | GET_SUINFO 901 | 返回 SU CPU/内存状态，可作为 SC 心跳 |
| SU | SEND_ALARM 603 / SEND_HISALARM 605 | 新告警及确认恢复主动上报；通信恢复后优先发送保存的历史队列 |

本次范围为实时数据查询与告警转发子集。遥测/遥信主动变化上送及历史补报、遥调、遥控、FTP、时钟修改、升级、端口信息、告警属性和控制逻辑未实现。对未实现的下行指令返回相应 ACK 的 Result=0，不调用 DCIM 控制、不改系统时间或执行重启。不能以本功能替代完整 B 接口一致性认证。

## 可靠性与恢复

“接入配置 → SoapUI / 告警 ACK 自动响应”提供“复制告警 ACK 脚本”和“复制响应正文”。先用响应正文 `${bAckEnvelope}` 完整替换 SC MockService → 方法 → Response 1 的 XML 正文，再把脚本粘贴到同一个 Response 1 底部的 **Script** 标签，启动 MockService。脚本不能放在 XML 正文或 Request 1 中。展开“查看 / 复制 Groovy 脚本”会自动生成；框旁也提供复制和重新生成按钮。SOAP 参数修改后请先保存；保存或重新加载后清除旧预览。HTTP 复制失败时选中全文并提示 Ctrl+C。

脚本按已保存的 SOAP 1.1/1.2、命名空间、方法、请求参数和响应字段生成，动态读取每条请求 SUId。LOGIN 101 返回 LOGIN_ACK 102 / RightLevel=1；LOGOUT 103、SEND_ALARM 603、SEND_HISALARM 605 分别返回 104、604、606 / Result=1。错误类型或 Code、非法 SUId、错误 SOAP 绑定、DTD/ENTITY、超过 2MB 或不可解析 XML 返回 SOAP Fault。它用于联调模拟，不鉴权账号、不保存告警；生成内容不含配置账号口令，不向 SC 发送请求，也不改变本软件注册状态或告警队列。接口沿用主壳登录校验，viewer 可生成和复制。

“接入配置 → SoapUI / Initial WSDL”区域提供“复制 LOGIN_ACK 响应”。展开“LOGIN_ACK 响应模板”时自动生成，响应框标题旁也提供“复制完整响应”按钮，滚动到文本框处即可直接复制。使用已保存的 SUId、SOAP 版本/命名空间/方法/响应字段生成完整 SOAP 响应，业务类型为 LOGIN_ACK（102）、RightLevel=1。粘贴到 SoapUI 的 SC MockService → invoke → Response 1，完整替换原内容，并启动 MockService；该模板仅用于模拟注册成功，不适用于告警 ACK。未保存修改不进入模板，SU 编码为空时提示先保存。HTTP 页面下剪贴板 API 不可用时自动尝试传统复制；复制仍失败时全文选中并提示 Ctrl+C。保存或重载配置后清除旧模板，重新展开重新生成；生成中/失败时文本框提供明确占位提示。接口需主壳登录，viewer 可用；生成不向 SC 发请求，不改变注册状态，不含注册账号密码。

运行日志表格单独设置时间、报文、结果与说明列宽，日期和时刻各一行，说明列占用剩余空间且完整换行；窄屏可在表格内横向滚动。结果显示“成功、失败、回退查询、部分失败、已接收、已跳过、未支持”等文字标签，悬停可查看原始英文结果值；颜色仅作辅助。默认最新日志在前，显示当前条数，无记录时提示“暂无运行日志”。这些显示调整不改变业务 ACK 判定或日志接口字段。

- 告警序号为十位数字，递增，最大 4294967295 后回绕；BEGIN/END 复用同一序号。恢复必须有合法的源恢复时间；告警消失、确认状态等均不作为恢复证据。
- 保留长期未恢复告警的原始发生时间作为历史查询下界，防止源接口按发生时间筛选时遗漏恢复。第一次启动不补发此前已经结束的全部历史告警。
- 仅在 HTTP 成功且 SOAP/业务 ACK 类型、Code、SUId、Result 均符合要求时出队；ACK 丢失时可能重复发送，上级应按 SUId+SerialNo+AlarmFlag 去重。
- 未确认队列和事件状态与配置一起原子保存；重启后未确认队列按 SEND_HISALARM 补报。DCIM 暂时不可用不会阻止已保存告警向 SC 补报。队列上限 10000 条，事件状态上限 20000 条，已结束记录保留 30 天；满时显示错误并保留原状态，不静默覆盖。
- 三个心跳周期未收到 SC 查询会重新注册。注册按 60–600 秒重试；同一注册地址三次失败后换下一地址。注册、心跳调度与 DCIM 采集间隔分开。
- DCIM 地址/路由变化会暂停转发，避免把旧映射套到新数据源。有未确认队列时禁止更换 SU、SC 或映射；仍允许停用。需要恢复原 DCIM/SC 连接完成补报后再切换。
- 文件损坏时停用且拒绝覆盖，需先备份并恢复有效文件；不会清空队列后继续发送。
- 数据超过三个采集周期未刷新时，遥测空值、遥信 FF，不把旧值冒充新值。
