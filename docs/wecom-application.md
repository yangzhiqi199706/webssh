# 企业微信自建应用（二期）

## 配置流程

1. 在企业微信管理后台创建自建应用，记录企业 CorpID、应用 AgentID、应用 Secret。
2. 设置应用可见范围，覆盖需要接收告警的成员；把 WebSSH 宿主机的出口公网 IP 加入应用可信 IP。无需配置消息接收回调。
3. 协议转换 → 企业微信转发 → 发送通道选择“自建应用”。填写应用参数，接收成员、部门或标签 ID，多个用 `|` 分隔，至少一种。成员可单独填 `@all`，含义是应用可见范围全部成员。
4. 保存后点击“验证应用凭证”。它只获取 Token，不发送消息，也不能证明全部接收人有效。
5. 点击“发送测试消息”，确认真实成员收到应用消息，再按需要开启自动转发。

## 行为与保护

- 与群机器人二选一，两套配置保留，历史配置默认群机器人。
- 首次自动采集仅建立基线；新增、明确恢复、筛选、去重及持久化重试沿用一期。
- 队列非空时禁止切换通道、更改企业/应用/接收对象。同一发送目标允许更新 Secret，以便凭证失效后重试。
- Secret 不回显，空值保持；与既有配置同文件保存，权限 0600。Token 仅存内存，提前 120 秒失效，40014/42001 刷新后重试一次。
- 应用发送启用企业微信 1800 秒重复检查；网络超时仍存在远端已接收但本地未确认的分布式投递不确定性，不承诺绝对恰好一次。
- 部分对象无效时，其他对象可能已收到。标记失败、停止自动重试，管理员核实后手动重试。
- 日志新增通道列。旧日志显示群机器人。凭证测试不记录 Token。

## 常见错误

- 60020：实际出口 IP 不在可信 IP 列表。
- 60011：接收人不在应用可见范围。
- 40013 / 40001：核对 CorpID 与应用 Secret。
- DNS 解析失败：在运行 WebSSH 的宿主机检查 `/etc/resolv.conf`，不是仅在 DCIM 容器内测试。
